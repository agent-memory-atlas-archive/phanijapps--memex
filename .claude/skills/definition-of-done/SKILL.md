# Definition of Done
A task or project is considered "done" when it meets all the predefined criteria, ensuring that it is complete, functional, and ready for review or deployment.


## Criteria
1. All unit tests have been written and passed successfully.
2. Code confrming to the project coding standards and guidelines.
3. Documentation has been updated to reflect the changes made. (example: README.md, CHANGELOG.md, docs/**, AGENTS.md, CLADUE.md, etc)
4. Code has been reviewed and approved by at least one other team member.
5. The feature has been tested in an environment that closely resembles production.
